简介

AppOptR 是一款 Android 应用线程 CPU 亲和性管理工具，基于规则配置文件，将指定应用的进程与线程绑定到指定的 CPU 核心簇，支持 eBPF 事件驱动与 /proc 轮询双模式，配置热加载及时生效，另支持按负载动态调度的 elect/load 规则。

使用说明
  1. 规则页点击「＋」，输入应用包名，可同时配置包级默认（可选）与多条线程规则后一次保存
  2. 设置页可切换 eBPF / Proc 工作模式、cpuset 目录名、检查间隔与配置文件路径
  3. 配置文件也可直接手工编辑，保存后自动热加载
  4. 更多规则编写说明参考官网文档和本仓库 README.md
